# Logo Arahin

Panah belok kuning (`#ffc700`) di atas abu gelap (`#16181a`), seperti marka jalan.

- `arahin.svg`: sumber logo (kotak penuh, untuk ikon app dan gambar sosial).
- `favicon.svg`: versi sudut membulat untuk tab browser.
- Turunannya dibuat dari kedua SVG itu: `favicon.ico` (16/32/48), `favicon-*.png`, `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png`, dan `social-1200.png`.

Ikon app di HP ada di `app/src/main/res/drawable/ic_launcher_foreground.xml` (vektor yang sama), dan ikon app jam di `watch/media/`.
